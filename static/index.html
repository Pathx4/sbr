ขั้นตอนการใช้งานจัดทำบันทึกข้อความ

  1. ตั้งค่า API Key: คลิกปุ่ม "ตั้งค่า API Key" ป้อนคีย์ (แนะนำคีย์ Groq API ใช้งานฟรี 100%) และกดบันทึก
  2. อัปโหลดภาพบิล/ใบเสร็จ: ลากไฟล์รูปภาพบิลมาวางที่กล่องอัปโหลดด้านซ้าย (รองรับการอัปโหลดหลายใบเสร็จพร้อมกัน)
  3. เลือกผู้จัดทำ: พิมพ์ชื่อบุคลากรในช่อง "ผู้จัดทำ / โทรศัพท์" → ระบบจะค้นหาและกรอกเบอร์โทร ชื่อ ตำแหน่ง ให้อัตโนมัติ
  4. แต่งข้อความด้วย AI: คลิกปุ่ม "ให้ AI วิเคราะห์จากรายการบิล" สีม่วง-น้ำเงิน AI จะวิเคราะห์สินค้าทั้งหมดแล้วกรอกข้ออ้างอิงกฎระเบียบพัสดุภาครัฐให้อัตโนมัติ
  5. ตรวจสอบและแก้ไข: ปรับแต่งรายการสินค้า เลขที่บิล ราคา วันที่ หรือแต่งเนื้อหาข้อความเกริ่นนำเองได้อิสระทางตารางฝั่งขวา
  6. สร้างไฟล์ Word: คลิกปุ่ม "สร้างไฟล์ Word" เพื่อดาวน์โหลดไฟล์บันทึกข้อความจัดซื้อจัดจ้าง (.docx) สำเร็จรูป

วิธีแชร์ให้เพื่อนร่วมงานใช้งานร่วมกัน

ระบบนี้เปิดให้เข้าใช้งานร่วมกันผ่านเครือข่ายภายในหน่วยงาน (Local Wi-Fi / LAN เดียวกัน) ได้ง่ายๆ:

  1. ค้นหา IP เครื่องเซิร์ฟเวอร์ (คอมพิวเตอร์ที่เปิดเซิร์ฟเวอร์):
    • เปิดโปรแกรม CMD (Command Prompt) ใน Windows
    • พิมพ์คำสั่ง ipconfig แล้วกด Enter
    • มองหาบรรทัด IPv4 Address (เช่น 192.168.1.100)
  2. ให้ผู้อื่นเข้าใช้งาน: เปิดเบราว์เซอร์แล้วพิมพ์ URL: http://[IP_เครื่องของคุณ]:5000 (เช่น http://192.168.1.100:5000)
ข้อสำคัญ: คอมพิวเตอร์เซิร์ฟเวอร์ต้องเชื่อมต่อเครือข่ายเดียวกับเพื่อนร่วมงาน และเปิดโปรแกรมเซิร์ฟเวอร์รันอยู่ตลอด (มีหน้าต่างรันคำสั่ง py app.py เปิดอยู่)
