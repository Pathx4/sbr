📝 คู่มือแนะนำการใช้งานและการย้ายโปรเจกต์ (README / Instructions)
========================================================================
โครงการ: ระบบจัดสรรงบประมาณอัจฉริยะ (Budget Allocation System v2.0)
พัฒนาโดย: Antigravity AI
========================================================================

โปรเจกต์นี้ประกอบด้วย 2 ส่วนหลัก:
1. frontend (React + Vite + TypeScript) - หน้ากากคำนวณและส่งออก Excel
2. backend (Python Flask) - ระบบดึงข้อมูลผู้บริหารและพนักงาน สทอภ. (GISTDA)

------------------------------------------------------------------------
⚠️ ข้อสำคัญที่สุดก่อนทำการบีบอัดไฟล์ (Zip) ลง Google Drive:
------------------------------------------------------------------------
*** รบกวนกดลบโฟลเดอร์ "frontend/node_modules" ทิ้งก่อนบีบอัดไฟล์! ***
เนื่องจากโฟลเดอร์นี้มีขนาดใหญ่มากและประกอบด้วยไฟล์ขนาดเล็กนับหมื่นไฟล์ 
หากไม่ลบจะทำให้การ Zip และการอัปโหลดขึ้น Drive ช้ามาก (อาจใช้เวลาหลายชั่วโมง) 
เมื่อนำไปเปิดที่เครื่องอื่นแล้ว ค่อยติดตั้งใหม่ได้ง่ายๆ ด้วยคำสั่งด้านล่างครับ

------------------------------------------------------------------------
💻 วิธีการติดตั้งและรันพัฒนาต่อที่เครื่องใหม่ (Development):
------------------------------------------------------------------------

ขั้นตอนที่ 1: ติดตั้งส่วนของ Frontend (React)
1. เปิดโปรแกรม Terminal หรือ Command Prompt ในเครื่องใหม่
2. เข้าไปที่โฟลเดอร์ frontend:
   > cd frontend
3. รันคำสั่งติดตั้ง Dependencies ใหม่ (พิมพ์คำสั่งนี้ในครั้งแรกที่เปิดเครื่องใหม่):
   > npm install
4. รันระบบเซิร์ฟเวอร์สำหรับพัฒนา:
   > npm run dev
   *(ระบบจะรันบน http://localhost:5173 หรือ port อื่นๆ ที่ระบุบนหน้าจอ)*

ขั้นตอนที่ 2: ติดตั้งส่วนของ Backend (Python Flask)
1. เปิด Command Prompt อีกหน้าต่างหนึ่ง
2. เข้าไปที่โฟลเดอร์ backend:
   > cd backend
3. ติดตั้ง Packages ที่จำเป็น:
   > pip install -r requirements.txt
4. รันเซิร์ฟเวอร์หลังบ้าน:
   > python app.py
   *(ระบบหลังบ้านจะรันบน http://localhost:5000)*

------------------------------------------------------------------------
🐳 วิธีการรันโปรเจกต์ด่วนด้วย Docker (ไม่ต้องลงโปรแกรมพัฒนา):
------------------------------------------------------------------------
หากเครื่องปลายทางมี Docker ติดตั้งอยู่แล้ว สามารถรันระบบทั้งหมดได้ทันทีโดยไม่ต้องลง Node.js หรือ Python:
1. เปิด Command Prompt ในโฟลเดอร์ backend
2. รันคำสั่ง:
   > docker-compose up -d --build
3. ระบบจะทำงานและเข้าใช้งานเว็บเวอร์ชันใช้งานจริงได้ทันทีที่ลิงก์:
   👉 http://localhost:5000  (หรือเข้าผ่านไอพีเครื่องเครื่องนั้นๆ)

------------------------------------------------------------------------
🚀 วิธีการ Build และอัปเดตหน้าเว็บจริง (Build & Deploy):
------------------------------------------------------------------------
เมื่อมีการแก้ไขโค้ดใดๆ เพิ่มเติมในโฟลเดอร์ src ของ frontend และต้องการอัปเดตเว็บจริง:

1. รันสคริปต์ประกอบไฟล์อัตโนมัติ (สคริปต์นี้จะแปลง React และย้ายไปยัง Flask อัตโนมัติ):
   > python build_and_deploy.py

2. การอัปเดตเว็บฝั่งหน้าบ้าน (Netlify):
   - ล็อคอินเข้าระบบที่ Netlify.com -> เลือกไซต์ของคุณ (sbr-budget)
   - ไปที่แท็บ Deploys
   - เลื่อนลงมาล่างสุด ลากโฟลเดอร์ "frontend/dist" ล่าสุดไปปล่อยในกล่องอัปโหลด

3. การอัปเดตระบบหลังบ้าน (Render):
   - เพียงแค่ใช้คำสั่ง git commit และ push ขึ้น GitHub
   - ระบบ Render backend (sbr-backend.onrender.com) จะทำการดึงโค้ดล่าสุดไปอัปเดตตัวเองอัตโนมัติครับ
