ขั้นตอนที่ 1: อัปโหลดรูปภาพบิล/ใบเสร็จ 📸

ลากไฟล์รูปภาพบิลมาวางในพื้นที่ฝั่งซ้ายมือ (สามารถอัปโหลดพร้อมกันหลายๆ ใบได้เลย) ระบบ AI จะทำการถอดรายการสินค้า ราคา และชื่อร้านให้อัตโนมัติ

ขั้นตอนที่ 2: แต่งประโยคด้วย AI 🤖

คลิกปุ่มสีม่วง "ให้ AI วิเคราะห์จากรายการบิล" (อยู่ทางขวามือ)
AI จะอ่านรายการสินค้าทั้งหมด แล้วช่วยเขียน "คำเกริ่นนำ" พร้อมคัดเลือก "ข้อกฎหมายพัสดุภาครัฐ" ที่ถูกต้องและสอดคล้องกับพัสดุในบิลให้อัตโนมัติ

ขั้นตอนที่ 3: ตรวจสอบและแก้ไข 📝

ตรวจสอบความถูกต้องของชื่อสินค้า จำนวนเงิน และกรอกชื่อผู้จัดทำ/ผู้อนุมัติให้เรียบร้อย หากต้องการแก้ข้อความตรงไหน สามารถพิมพ์แก้ในตารางได้เลย ระบบจะคำนวณยอดเงินรวมให้ใหม่ทันที

ขั้นตอนที่ 4: สร้างไฟล์ Word 📄

เมื่อข้อมูลถูกต้องครบถ้วนแล้ว ให้กดปุ่ม "สร้างไฟล์ Word" ด้านล่างขวา ระบบจะดาวน์โหลดไฟล์ .docx สำเร็จรูปให้คุณนำไปปริ้นท์และเสนอเซ็นได้ทันที!

ข้อควรรู้เพิ่มเติม

  • เรื่อง API Key: ระบบนี้ได้รับการตั้งค่าคีย์ AI จากเซิร์ฟเวอร์ไว้เรียบร้อยแล้ว คุณไม่ต้องเข้าไปตั้งค่า API Key ใดๆ ในหน้าเว็บอีก ใช้งานได้เลยครับ!
  • การพิมพ์ชื่อบุคลากร: เมื่อคุณเริ่มพิมพ์ชื่อในช่อง "ผู้จัดทำ" หรือ "ผู้อนุมัติ" ระบบจะแสดงรายชื่อจากฐานข้อมูลขึ้นมาให้เลือก เพื่อความรวดเร็วและไม่ต้องพิมพ์ซ้ำ
